# SpM-lab/.github

- `profile/README.md` is the landing page shown at https://github.com/SpM-lab.
  The website https://spm-lab.github.io/ (source: SpM-lab/SpM-lab.github.io) is
  the main entry point; keep the two consistent.
- The issue tracker of this repository is for work that spans several SpM-lab
  projects (documentation across sites, conventions shared by the libraries,
  releases that touch more than one package). Issues about a single library
  belong in that library's repository and can be transferred there.
